# Retail Sales Analysis Using Python

## Project Overview
This project analyzes retail sales data using Python to understand sales performance, product category trends, and customer purchasing behavior.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Information
The dataset contains 1,000 retail transactions and 9 columns:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Data Cleaning
- Checked for missing values.
- Checked for duplicate records.
- Converted Date into datetime format.
- Verified data types.

## Key Business Insights
- Total Revenue: 456,000
- Total Transactions: 1,000
- Average Order Value: 456
- Total Quantity Sold: 2,514
- Top Performing Product Category: Electronics

## Data Visualizations
Four charts were created:
1. Monthly Sales Trend
2. Revenue by Product Category
3. Sales by Gender
4. Sales by Age Group

## Project Structure
- data/ – Dataset
- visualizations/ – Generated charts
- retail_sales_analysis.py – Python analysis code
- README.md – Project documentation

## Conclusion
This project demonstrates how Python can be used to clean, analyze, and visualize retail sales data to generate meaningful business insights.
